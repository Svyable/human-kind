# Principles

1. **Evidence before confidence.** Match certainty to source quality and directness.
2. **Scope before scale.** Make the problem and intervention bounded enough to test.
3. **Mechanisms over slogans.** Explain how an intervention is expected to cause change.
4. **Falsifiability matters.** State what evidence would change the central claim.
5. **Participation is part of quality.** Affected communities help define harms, benefits, and acceptable tradeoffs.
6. **Safety is a design input.** Consider misuse, externalities, reversibility, and failure modes early.
7. **Negative results are assets.** Preserve declined paths and failed pilots with reasoning.
8. **Open where responsible.** Make work verifiable and reusable without publishing details that create avoidable harm.
9. **Agents assist; humans decide.** Automation can improve research throughput but does not remove accountability.
10. **Measure action, not applause.** Optimize for learning and outcomes rather than attention or repository popularity.
