# Security Policy

Human Kind contains research, automation, and agent workflows. Security reports may include software vulnerabilities, prompt/tooling abuse paths, secret exposure, unsafe automation behavior, or repository supply-chain risks.

## Reporting

If GitHub private vulnerability reporting is enabled for this repository, use it for sensitive reports. Otherwise, open a minimal public issue stating that you have a sensitive security concern and request a private contact path; do not include exploit details, secrets, personal data, or harmful reproduction steps in the public issue.

## Scope

Please report vulnerabilities in repository code, Actions workflows, schemas, agent harnesses, or generated public-index tooling. For harmful content or research-governance concerns that are not software vulnerabilities, use the governance process instead.

## Handling

Maintainers should acknowledge reports, limit unnecessary disclosure, assess exploitability and downstream harm, patch before broad publication when appropriate, and document security-relevant changes after the risk is controlled.
