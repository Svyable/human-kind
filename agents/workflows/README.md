# Agent workflows

Workflows should compose constrained roles with explicit handoffs. Initial targets:

1. source research: Scout → Synthesizer → human verification;
2. skeptical review: Skeptic + Red Team → human adjudication;
3. taxonomy: Taxonomist → schema validation → human acceptance;
4. pilot design: Synthesizer → Pilot Designer → domain/safety review → accountable owner.

No workflow may make a consequential decision merely because all agent steps agree.
