### Problem statement

Coastal communities need a bounded way to compare local flood-preparedness interventions before committing resources to irreversible infrastructure choices.

### Proposed intervention

Create a standardized evidence worksheet for comparing small, reversible preparedness interventions before capital deployment.

### Theory of change

If local teams compare candidate interventions using the same evidence, risk, cost, and reversibility fields, then weak options can be identified earlier and better questions can be tested before large commitments.
