## Problem

Synthetic and heavily edited media make source and edit history harder to assess at scale. C2PA provides a technical standard for cryptographically verifiable content provenance, but provenance is not the same as truth, adoption is incomplete, metadata can be absent, and identity/privacy design can create new harms.

## Proposed intervention

Design and evaluate a public-interest provenance UX standard for high-impact media that makes available C2PA-style origin/edit signals understandable while explicitly distinguishing four states: verified provenance, unverifiable provenance, absent provenance, and contradictory provenance. Never label uncredentialed media as false merely because credentials are missing.

## Theory of change

If provenance signals are interoperable and presented with calibrated semantics, users and institutions may gain useful context about media origin and modification without relying on brittle synthetic-media detectors or turning a credential system into an arbiter of truth.

## Falsification condition

Users systematically misunderstand provenance as truth, credentials create unacceptable exclusion or privacy harms, adversaries can cheaply exploit trust signals, or provenance UX does not improve calibrated judgments compared with existing context.

## Smallest responsible next step

Build a no-production mock evaluation using public sample media representing valid, absent, broken, and contradictory provenance. Test whether candidate language helps people understand what is and is not established. No platform deployment.
