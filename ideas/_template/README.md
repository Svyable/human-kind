# Idea dossier template

Copy this directory to `ideas/<primary-domain>/<descriptive-slug>/` and replace all placeholders.

Keep `idea.yaml` compact and machine-readable. Put reasoning in the Markdown files. Every material status change should be explained in `updates.md`.

A dossier is ready to leave `intake` only when its central claims, evidence gaps, risks, affected stakeholders, and next action are legible to an independent reviewer.
