# Reviews

This directory holds structured reviews of the dossier.

Each substantive review should have a machine-readable `.yaml` artifact and a human-readable `.md` twin. Reviews preserve disagreement and provenance; they do not silently modify `idea.yaml`.

Agent reviews must follow [`../../../docs/agent-protocol.md`](../../../docs/agent-protocol.md) and have `decision_authority: none`.

See [`../../../docs/triage.md`](../../../docs/triage.md) for how reviews inform lifecycle decisions.
