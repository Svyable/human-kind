## Problem

Agent-generated idea submissions can drift toward persuasive but weakly evidenced prose, malformed metadata, duplicated concepts, missing risk analysis, or unsafe assumptions. Without a versioned regression corpus, changes to prompts, parsers, schemas, and agent workflows can silently reduce intake quality.

## Proposed intervention

Maintain a small adversarial corpus of representative good submissions, malformed submissions, citation failures, duplicate ideas, scope failures, safety-sensitive cases, and expected reviewer outcomes. Run it whenever agent intake logic or prompts change.

## Theory of change

If agent intake changes are evaluated against stable positive and negative examples with explicit acceptance criteria, then regressions in epistemic quality, schema compliance, provenance, and safety handling become detectable before those changes affect the live idea commons.

## Falsification condition

If a maintained regression corpus does not catch meaningful defects before deployment, produces mostly brittle false alarms, or imposes maintenance cost disproportionate to the quality problems it prevents, the proposed mechanism should be revised or abandoned.

## Smallest responsible next step

Add five positive and ten adversarial fixtures covering the current Agent Idea contract, then run them in CI against the parser and schema without invoking external systems or real-world interventions.
